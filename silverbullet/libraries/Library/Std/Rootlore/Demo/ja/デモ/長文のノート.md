# 長いノートの見え方

見出しが深くなると、左に線が出て、どこを読んでいるかが分かります。
長いノートでも、見出しをたどって読めるようになっています。

## 1. 名前を決めるまで

最初は名前が決まっていなかった。仮の名前で作り始めて、あとから変えると、
ファイルの名前も、リンクも、案内文も、全部を直すことになる。
だから先に名前を決めた。

### 候補

- 案A: ノートを置く場所を表す名前
- 案B: 知識が根づく様子を表す名前
- 案C: 手元に戻す、という意味の名前

### 決め手

案Bにした。ノートは書いた瞬間より、あとから読み返したときに価値が出る。
根づいて育つ、という言い方が、その感覚に近かった。

## 2. 料金をどうするか

無料でできることを広く取るか、狭く取るかで議論になった。

> 使ってもらえないと、どこが使いにくいかも分からない。
> まずは広く開けて、負担が大きいところだけを有料にする。

この方針で進めることにした。くわしくは [[デモ/議事録]] にある。

## 3. 公開までにやること

1. 画面の作り込み（11/15）
2. 案内文（11/18）
3. 動作の確認（11/20）
4. 公開（11/25）

### 確認すること

- [ ] 新しい端末でログインできる
- [ ] ノートが読める
- [ ] 直して保存できる
- [ ] 2台で同時に直しても、消えない

## 4. コードを書く場合

```js
const notes = await fetchNotes();
const recent = notes
  .filter((note) => note.updatedAt > Date.now() - 7 * 24 * 60 * 60 * 1000)
  .sort((a, b) => b.updatedAt - a.updatedAt);
```

コードのブロックは、右上のボタンで写せます。
