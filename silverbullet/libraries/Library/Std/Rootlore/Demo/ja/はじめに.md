# これは見本のノートです

GitHub につなぐ前に、Rootlore がどんな画面になるかを見せるための見本です。
**つなぐと、この見本は消えます。** あなたのノートに置き換わります。

## できること

- ノートを読む。リンクをたどる
- 検索する（⌘K か ⌘P）
- 直して保存する（⌘E で編集、⌘S で保存）
- フォルダごとに整理する

## まず触ってみる

1. 左の一覧から [[デモ/プロジェクト計画]] を開く
2. 文中のリンクを押して、別のノートに移る
3. ⌘K で「議事録」と打って、検索してみる

## リンクの書き方

`[[ノートの名前]]` と書くと、そのノートへのリンクになります。
`[[デモ/議事録]]` のようにフォルダを書いてもかまいません。

## 画面の見え方

| 場所 | 何が出るか |
| --- | --- |
| 左のサイドバー | フォルダとノートの一覧 |
| 上のバー | 開いているノートの名前 |
| 本文 | ノートの中身（この画面） |
| サイドバーの下 | 設定・アカウント・紹介 |
