# This is a sample note

This sample shows what Rootlore looks like before you connect GitHub.
**Once you connect, this sample goes away** and your own notes take its place.

## What you can do

- Read notes and follow links
- Search (⌘K or ⌘P)
- Edit and save (⌘E to edit, ⌘S to save)
- Organize with folders

## Try it

1. Open [[Demo/Project plan]] from the list on the left
2. Follow a link in the text to move to another note
3. Press ⌘K, type "Meeting", and see the search

## Writing links

`[[Note name]]` creates a link to that note.
You can include a folder, like `[[Demo/Meeting notes]]`.

## What you see

| Where | What appears |
| --- | --- |
| Sidebar | Folders and notes |
| Top bar | The name of the open note |
| Main area | The note itself (this screen) |
| Bottom of the sidebar | Settings, account, share |
