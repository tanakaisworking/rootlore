# Code of conduct

Rootlore follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work. Harassment and personal attacks are not accepted in issues, pull requests, or any other project space.

To report a problem, contact the maintainer, [@tanakaisworking](https://github.com/tanakaisworking), on GitHub. Reports are handled privately.
