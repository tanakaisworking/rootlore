# Security policy

Report security problems privately through [GitHub's security advisories](https://github.com/tanakaisworking/rootlore/security/advisories/new). Do not open a public issue.

Please include what you found, how to reproduce it, and which part is affected (Mac app, web version, or CLI). Do not include real note contents or tokens.

We reply within a few days and credit you in the fix unless you ask us not to.
